# ADO-02 / ADO-03 / CAP-04 — ชุดทดสอบเวลาสร้างเคสกับผู้ใช้จริง

เกณฑ์จาก PRD:
- ผู้ใช้ที่อบรม 5 นาที สร้างเคสเสร็จภายใน 30 วินาที (CAP-04)
- ทดสอบอย่างน้อย 5 คนที่ไม่เคยเห็นระบบ เทียบกับการกรอก Google Sheet เดิม (ADO-02)
- สรุปผลและแก้ปัญหาที่เจอก่อนปิด Phase 1 (ADO-03)

## เตรียมก่อนวันทดสอบ
- เปิดระบบ (staging หรือเครื่องทีม) และเตรียมข้อมูลตัวอย่าง: `python scripts/seed_demo.py --apply`
- สร้างบัญชีผู้ทดสอบบทบาท Agent คนละบัญชี ห้ามใช้ข้อมูลลูกค้าจริง
- เปิด Google Sheet แบบเดิมที่ทีมใช้ไว้อีกหน้าต่างหนึ่ง สำหรับวัดเทียบ
- ผู้คุมการทดสอบเปิดหน้า **รายงาน → เวลาที่ใช้สร้างเคส** ไว้ (ระบบวัดเวลาให้อัตโนมัติ)

## อบรม 5 นาที (อ่านตามนี้)
1. นาทีที่ 1: หน้า "งานของฉัน" คือคิวงาน ปุ่ม "สร้างเคส" อยู่มุมขวาบน
2. นาทีที่ 2: กรอกแค่ 3 ช่อง ลูกค้า (พิมพ์ชื่อหรืออีเมลแล้วเลือก) หัวข้อ และช่องทาง
3. นาทีที่ 3: ถ้ามีกล่อง "เคสที่คล้ายกัน" ให้เลือก "เปิดสอบสวนใหม่" ถ้าไม่ใช่เรื่องเดียวกัน
4. นาทีที่ 4: กด "สร้างเคส" ระบบจะพาไปหน้าเคสพร้อมเลขเคส
5. นาทีที่ 5: ให้ผู้ทดสอบลองเองหนึ่งครั้ง (ไม่นับผล)

## โจทย์ที่ใช้วัด (ให้ทำทั้งในระบบและใน Google Sheet สลับลำดับกันระหว่างคน)
| # | สถานการณ์ที่อ่านให้ฟัง | ลูกค้า | ช่องทาง |
|---|---|---|---|
| 1 | อาจารย์โทรมาบอกว่านักศึกษาดาวน์โหลดข้อสอบไม่ได้ทั้งห้อง | มหาวิทยาลัยตัวอย่าง (DEMO) | โทรศัพท์ |
| 2 | LINE OA: ขอเพิ่มสิทธิ์อาจารย์เข้ากลุ่มรายวิชา | มหาวิทยาลัยตัวอย่าง (DEMO) | LINE OA |
| 3 | อีเมล: แพทย์ฝึกหัดบันทึกหัตถการไม่สำเร็จ | โรงพยาบาลตัวอย่าง (DEMO) | อีเมล |

## บันทึกผล
เวลาในระบบดูจากหน้ารายงาน (นับตั้งแต่เริ่มกรอกจนสร้างสำเร็จ) ส่วน Google Sheet ใช้นาฬิกาจับเวลา

| ผู้ทดสอบ | ตำแหน่ง | อุปกรณ์ | โจทย์ | เวลาในระบบ (วินาที) | เวลา Google Sheet (วินาที) | ปัญหาที่เจอ |
|---|---|---|---|---|---|---|
| | | | | | | |

**ผ่านเกณฑ์** เมื่อค่ากลางของเวลาในระบบ ≤ 30 วินาที และเร็วกว่า Google Sheet ในผู้ทดสอบส่วนใหญ่
